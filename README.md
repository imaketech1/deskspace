# DESKSPACE

## A Virtual Co-working Space for Focus and Collaboration

DeskSpace is a real-time virtual environment designed to enhance productivity and connection. It combines a Pomodoro timer, task management, and a virtual library where users can work, chat, and collaborate with others in real-time.

## 🎯 Key Features

### Focus Mode
- **Pomodoro Timer**: Stay focused with customizable focus sessions
- **Task Management**: Organize tasks with drag-and-drop functionality
- **Study Stats**: Track daily focus time and productivity

### Virtual Library
- **Real-time Multiplayer**: Explore the library with other users
- **Interactive Zones**: Move through different themed areas:
  - 📚 **Library** - Quiet reading and study area
  - ☕ **Tea Room** - Socialize and chat with others
  - 🖥️ **Computer Room** - Collaborative desk area
  - 🌿 **Garden** - Relax in a peaceful outdoor setting

### 🎨 Personalization
- **Theme Picker**: Customize your environment
- **Sound Selection**: Choose ambient sounds for focus
- **Profile Management**: Set your username and avatar
